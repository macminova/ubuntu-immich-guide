# 公開資料の安全性

実.env、パスワード、APIキー、秘密鍵、Tailscaleの認証キー、実ホスト名、接続先IP、SSDの固有識別子、写真、DBダンプ、SSH設定の実物を追加しないでください。

不具合を報告するときも、個人情報や秘密値を伏せ、試験用の値で再現してください。秘密情報が混入した場合は公開issueへその内容を貼らず、公開を止めて対応方法を確認してください。専用の非公開連絡窓口は公開前に設定します。

`.gitignore`は未追跡ファイルの誤追加を減らすものです。すでにGitで追跡したファイルや過去の履歴を消す機能はありません。運用リポジトリの履歴を公開用へ持ち込まないでください。

付属の検査スクリプトは既知パターンの検出補助です。検査に通ることを安全性の証明にしないでください。
