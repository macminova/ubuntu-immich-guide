# 構築ガイドを作る順番

現在は構成解説と例の準備段階です。以下を検証しながら、再現可能な構築手順へ進めます。

1. 想定ハードウェア、OS、採用版、バックアップ先を決める。
2. LinuxとDocker Composeの前提を公式資料で確認する。
3. 外付けSSDを識別し、マウントと未接続時の停止を設計する。
4. 採用するImmichリリースの公式Composeと環境変数例を取得する。
5. 写真保存先・DB保存先・固有パスワードをローカルで設定する。
6. Composeの最終展開内容を確認する。秘密値を含む出力を公開しない。
7. Tailscaleとホスト・Docker双方のアクセス制御を設定し、非許可経路から到達しないことを試験する。
8. 個人写真を使う前に、試験画像のアップロード・表示・取得を確認する。
9. DBと写真のバックアップ、隔離環境への復元を検証する。
10. 更新・失敗時の復旧手順を作り、確認した版と日付を添えて公開する。

公式の入口

- [必要環境](https://docs.immich.app/install/requirements/)
- [Docker Compose](https://docs.immich.app/install/docker-compose/)
- [バックアップと復元](https://docs.immich.app/administration/backup-and-restore/)

最新ドキュメントのコマンドを過去の採用版にそのまま適用できるとは限りません。版が違う場合は、リリースノートと当該版の構成を確認してください。
